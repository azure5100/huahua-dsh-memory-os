# 项目文件通用模板

本目录存放项目全生命周期所需的标准化文档模板，供团队协作项目使用。

## 模板列表

| 文件 | 级别 | 用途 | 使用时机 |
|------|------|------|---------|
| `L1_项目蓝图.md` | L1 | 项目整体方案：目标、时间线、分工矩阵、边界声明、验收标准 | Stage ① 方案设计，入职流程 |
| `L2_施工记录.md` | L2 | 每位成员的个人工作日志：时间线、交付物、问题与决策 | Stage ③ 并行交付全程 |
| `L3_项目纪要.md` | L3 | 项目总结：时间线总览、关键决策、偏差记录、经验教训 | Stage ⑦ 报告归档 |
| `角色任命书.md` | — | 成员入职文件：角色定义 + 本项目边界声明 | 入职流程 Step 1 |
| `阶段任务卡.md` | — | 每个 Stage 入口的任务下发：目标、任务、边界重申 | 入职流程 Step 3 / 每个 Stage 入口 |
| `handoff.md` | — | **交接件规范**：五节内容 + `stage` 必填 + 生成时机 + 门 | 里程碑交付 / 成员被替换或下线前 / 遇到阻塞需他人接手时 |

## 三级文件体系

```
项目文件夹/
├── L1_项目蓝图.md          ← 团队共同制定，项目牧羊人协调
├── L2_施工文件/             ← 每位成员独立维护
│   ├── [角色1]_施工记录.md
│   ├── [角色2]_施工记录.md
│   └── [角色3]_施工记录.md
└── L3_项目纪要.md          ← 项目牧羊人汇总

每个成员的产出
├── 📦 项目交付物（给项目的）
└── 📝 施工记录报告（给档案的）
```
