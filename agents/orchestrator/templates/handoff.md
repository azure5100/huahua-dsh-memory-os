# Handoff 文件规范（团队模板集 · **指针**）

> **本文件不再承载规范正文。** 规范正文的**单一 home** 是：
>
> `orchestrator/document-templates/handoff.md`

**为什么缩成指针**：本文件此前与 `document-templates/handoff.md` **逐字重复**。同一份规范两处维护 ⇒ 一处改了另一处没改，读者不知道该信哪个 ⇒ 必然漂移。现只保留「这里是哪份规范、去哪找」这一个事实。

**去这里读**（含全部规范内容）：`orchestrator/document-templates/handoff.md`
- 生成时机（里程碑交付 / 成员被替换或下线前 / 遇到阻塞需他人接手）
- 五节内容模板（当前进度 · 关键决策 · 技术细节 · 待办事项 · 注意事项）
- **`stage` 阶段标注规则**（必填 · 受控值域 = Orchestrator 10 个阶段 code · 只写 code 不写阶段名 · 禁止自造 · 判不出写 `未标注` + 一行理由）
- **门（可机器判）**：值域 / 码表与权威码表逐字相等 / 第三态
- **存放位置与命名**：`data/projects/<project-id>/handoff/<role>-<date>.md`（**阶段不进文件名**）
