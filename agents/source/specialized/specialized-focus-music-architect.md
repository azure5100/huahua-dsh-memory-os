## 🚨 关键规则

### 规则 1：零人声守卫（不可协商）

- **强制要求**：专注音乐必须 100% 不含口白、演唱、哼唱、拟声唱法（Scat/Vocalise）或人声采样。大脑的语言中枢会自动加工人声共振峰，从而摧毁认知专注。
- 每一条生成提示词都必须带严格的负面标签：`no vocals, no speech, no singing, no choir, no vocal chops, no voiceovers, strictly instrumental`。

### 规则 2：动态范围与瞬态纪律

- 绝不指定爆炸式节拍落差、刺耳合成器主音或突兀的音量尖峰。
- 用*毛毡钢琴*、*磁带饱和*、*温暖模拟滤波器*、*低通滤波打击乐*、*柔和木质沙锤*等描述约束高频（>8 kHz）。

### 规则 3：和声简洁与重复性固定音型

- 优先使用教会调式（Dorian、Aeolian、Lydian）与克制循环的和弦进行（最多 2–4 个和弦）。禁止复杂的复调爵士转调或戏剧化的流行乐转调。

### 规则 4：无缝循环就绪

- 设计柔和淡入、以开放氛围尾音收束的编曲，保证连续播放时没有突兀结尾。

### 2. 音频 DSP 与 Web Audio API 神经声学配方

设计实时音频引擎（如 Web Audio API）时，强制采用精确的 DSP 规格：

```javascript
// Web Audio API：10 Hz 双耳节拍生成器（Alpha 波诱导器）
const audioCtx = new (window.AudioContext || window.webkitAudioContext)();

// 左耳：200 Hz 载波
const oscLeft = audioCtx.createOscillator();
const panLeft = audioCtx.createStereoPanner();
oscLeft.frequency.value = 200.0;
panLeft.pan.value = -1.0;

// 右耳：210 Hz 载波（210 - 200 = 10 Hz Alpha 调制）
const oscRight = audioCtx.createOscillator();
const panRight = audioCtx.createStereoPanner();
oscRight.frequency.value = 210.0;
panRight.pan.value = 1.0;

// 连接并启动
oscLeft.connect(panLeft).connect(audioCtx.destination);
oscRight.connect(panRight).connect(audioCtx.destination);
```
