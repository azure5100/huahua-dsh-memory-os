# 产品线 09 · 邀请函

> 唯一 KPI：读者一屏内知道「什么事、何时、何地、怎么去」。


## 何时进这条线

```
用户要：活动邀请 / 婚礼请柬 / 会议邀约 / 开幕邀请
关键词：邀请函、请柬、邀约、invitation
⚠️ 要大范围宣发（不指名）→ 那是「海报」；邀请函是给「具体的人」的
```

## ① 规格

```
手机版   1080×1920（一屏读完）或 1080×1440
印刷版   5×7 inch（127×178mm）或 A5（148×210mm），+出血 3mm
双面      正面=事件与视觉，背面=详情与二维码
二维码    ≥20mm（印刷）/ ≥120px（屏幕），四周留白 ≥4 个模块
字号下限  屏幕正文 ≥28px @1080 宽；印刷正文 ≥9pt
```

## ② 必填要素（缺一不算交付）

```
□ 四要素齐全且优先级最高：什么事 / 何时 / 何地 / 怎么去
□ 主人名或称呼位（邀请函是「给你」的，不是群发）
□ 二维码或链接（报名/地图/直播），且可扫
□ 主办方与联系方式
□ 载体已声明（手机长图 / 印刷单面 / 印刷双面）
```

## ③ 流程四步

```
Step 1  先定载体：只在群里发（屏幕）？要印出来（印刷）？两者都要？
Step 2  排四要素（先文字排版，把「何时何地」放到最显眼处）
Step 3  加视觉（不要为了视觉挪动四要素的位置）
Step 4  一屏测试 / 打印测试 + 二维码实扫一次
```

## ④ 门禁三条

```
1. 一屏（或卡片一面）内读完四要素，不需要滚动/翻面
2. 二维码实测能扫（用手机真扫，不是看着像）
3. 时间地点零歧义（写「周六 19:00」不够，要写日期；写地址要到门牌）
```

## 常见返工点

```
· 做成活动海报：视觉很满，但读者找不到「几号几点在哪」
· 二维码太小或留白不足 → 扫不出（这条最高频）
· 只写「本周六」不写日期 → 转发后失效
· 印刷版没出血 → 裁切吃掉边框
```
