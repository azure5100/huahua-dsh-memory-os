# 产品线 00 · 想法

> 把一个模糊的念头变成「能往下走的方向」，不是变成成品。


## 何时进这条线

```
用户说：「我有个想法」「想做点什么」「帮我看看这个方向行不行」
关键词：还没有明确形态、说不清要什么、需要先看可能性
```

## ① 规格

```
画幅    无硬约束（低保真阶段不锁尺寸）
保真度  低：盒子 + 字 + 箭头，不用真色、不用真图、不做动效
数量    固定 3 个方向，不多不少
交付    HTML 单页并列三栏（可点击切换），或三张 1600×900 截图
```

## ② 必填要素（缺一不算交付）

```
□ 一句话定位：给谁看 · 看完要做什么
□ 3 个方向的差异必须能一句话说清（不是换配色，是换思路）
□ 每个方向标「成立条件」：它依赖什么假设
□ 明确「下一步进哪条产品线」（原型 / 落地页 / 海报 …）
```

## ③ 流程四步

```
Step 1  问 3 个问题（不超 3 个）：给谁看 / 看完做什么 / 有没有硬约束（尺寸·品牌·时间）
Step 2  出 3 个低保真方向：盒子+字，灰阶即可，禁止调色（调色会让人爱上细节而忽略方向）
Step 3  每个方向写「成立条件」与「会死在什么地方」
Step 4  等用户选 → 记录选择理由 → 转交对应产品线
```

## ④ 门禁三条

```
1. 3 个方向齐全，且差异是「思路差异」不是「配色差异」
2. 全部是低保真（无真图、无渐变、无动效）—— 有一样就算越界
3. 用户已明确选定一个方向，且选定理由被记录
```

## 常见返工点

```
· 一上手就精修 → 方向错了全废（最贵的返工）
· 出 6-8 个方向 → 用户选择疲劳，反而选不出来
· 3 个方向其实是同一个思路的三种配色 → 等于只给了 1 个方向
```
