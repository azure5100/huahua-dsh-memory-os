# 产品线 04 · logo

> 标志的成立不在「好看」，在「缩小、单色、反白三种情况下都还站得住」。


## 何时进这条线

```
用户要：品牌标志 / 图标 / 字标 / favicon / 系列图标
关键词：做个 logo、品牌名视觉化、App 图标
⚠️ 只是「用别人现成的 logo」→ 走 references/brand-asset-protocol.md，不进这条线
```

## ① 规格

```
矢量母版  SVG（唯一真相源），viewBox 见方
导出套件  SVG + PNG 16/32/48/64/128/256/512/1024（透明底）
单色版    纯黑 + 纯白（反白）各一份
安全区    四周留白 ≥ 标志主体高度的 1/4
最小尺寸  图标型 ≥16px 高；字标型 ≥80px 宽
```

## ② 必填要素（缺一不算交付）

```
□ 3 个方向（具象 / 几何 / 字标），且思路不同不只是配色
□ 单色版与反白版都成立（不是彩色版转灰就算）
□ 16px favicon 测试通过
□ 网格与安全区图（说明为什么是这个比例）
□ 交付套件齐全（SVG 母版 + 多尺寸 PNG + 单色/反白）
```

## ③ 流程四步

```
Step 1  问品牌三件事：做什么的 / 和谁不同 / 会被用在哪（App 图标？门头？名片？）
Step 2  3 个方向草稿（黑稿，不上色）→ 用户选 1
Step 3  把选中的做成几何：网格对齐、光学修正（圆的直径比方视觉更大）
Step 4  三种压力测试（16px / 单色 / 反白）→ 导出套件
```

## ④ 门禁三条

```
1. 16×16 px 下仍能辨认（不是「大概看得出是圆的」，是能认出是这个标志）
2. 纯黑单色印刷成立：没有依赖颜色区分的部分
3. 反白（深底白标）边缘不发虚，细线 ≥1px @16px
```

## 常见返工点

```
· 只交彩色大图 → 落到 App 图标/工牌/单色印刷立刻崩
· 细节过多（渐变、阴影、多层）→ 缩小即糊
· 用字库字体当字标却不转曲 → 换机就变形
· 忘记光学修正 → 圆和方看起来不等大
```
