# 产品线档案卡 · 固定格式（新增产品线照此写）

```
# 产品线 NN · 名称
> 一句话定位（它解决什么、不解决什么）

## 何时进这条线        —— 触发词 / 与相邻线的分界
## ① 规格             —— 尺寸 / 分辨率 / 画幅 / 交付形态（可查表）
## ② 必填要素         —— 缺一不算交付的清单（□ 打勾项）
## ③ 流程四步         —— 这条线特有的顺序，不是通用流程
## ④ 门禁三条         —— 优先可机器验证（缩略图可辨 / 三视口 / 16px / 无孤行）
## 常见返工点         —— 踩过的坑，写现象不写道理
## 复用资源           —— 指向 references/assets/scripts
```

**硬规则**：门禁必须能被人当场判定（最好能写脚本）；写不出门禁的产品线，先别加。
