# 产品线 08 · 插画

> 一张图讲一个概念，服务于论点，不是装饰。


## 何时进这条线

```
用户要：正文配图 / 概念可视化 / 示意图 / 抽象概念图
关键词：配一张图、illustration、概念图、解释一下这个
⚠️ 要「精确结构 + 物理感 + 能打印」→ 走「3D演示」线（等距工艺图）
⚠️ 要「数据驱动 + 多图表」→ 走 references/scene-templates.md §3 信息图
```

## ① 规格

```
16:9   1200×675（最通用，配文章）
1:1    800×800 或 1080×1080（强调 / 社交）
4:3    1200×900（信息较多时）
竖版    1080×1920（手机长图阅读）
背景    与文章底色一致（浅底文章用浅底图，不要硬切）
```

## ② 必填要素（缺一不算交付）

```
□ 一个核心概念（不是三个概念的拼贴）
□ 能一句话说出「这张在讲什么」（写进交付说明）
□ 调性与文章一致（温度/明暗/繁简）
□ 与相邻插图手法不重复（节奏感）
□ 图内无错别字，无乱码字符
```

## ③ 流程四步

```
Step 1  从正文里提「一个」可被图像化的句子（不是整段）
Step 2  选表达方式：隐喻 / 剖面 / 对比 / 流程（四选一）
Step 3  定调性（参考 references/design-styles.md 的温度分级）
Step 4  出图 → 遮住正文自测 → 与前后图对比节奏
```

## ④ 门禁三条

```
1. 遮住正文，能说出这张在讲什么（说不出来 = 只是装饰）
2. 与相邻两张不重复同一手法（隐喻/剖面/对比/流程）
3. 图内文字零错别字，字号在缩略图下可辨（≥18px @1200 宽）
```

## 常见返工点

```
· 画得好看但不服务论点（最常见的「漂亮废图」）
· 一张图塞三个隐喻 → 读者一个都没记住
· 与封面用同一构图 → 系列里两张图互相打架
```
