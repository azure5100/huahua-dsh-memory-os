# 产品线 02 · 落地页

> 一屏抓住、一路说清、一处转化。核心不是好看，是「说服链完整」。


## 何时进这条线

```
用户要：产品官网 / 活动页 / 介绍页 / 等待名单页
关键词：让人来注册、说清楚我们做什么、投广告要用
```

## ① 规格

```
设计宽度  1440px，响应式到 320px
首屏      100vh，5 秒内说完核心价值
断点      1440 / 1024 / 768 / 390 四档
字号      首屏主标题 ≥56px（1440 下），正文 ≥17px
图片      首屏主图 ≤300 KB，全页图 ≤1.5 MB
```

## ② 必填要素（缺一不算交付）

```
□ 首屏三件套：一句价值主张 / 一个主 CTA / 一个视觉证据（截图或产品图）
□ 滚动叙事四段齐全：问题 → 方案 → 证明 → 行动
□ CTA 至少出现两次（首屏 + 结尾），文案一致
□ 移动端 390px 下首屏不需要横向滚动
□ 页脚有真实联系方式（不是 lorem）
```

## ③ 流程四步

```
Step 1  写「一句话价值」草稿 ×3，选最不像广告语的那句
Step 2  排滚动叙事四段骨架（先文字后视觉，避免被配图牵着走）
Step 3  做首屏（最重要的一屏，做到满意再往下）
Step 4  四断点响应式 + 性能核对
```

## ④ 门禁三条

```
1. 1440 / 768 / 390 三视口截图，首屏内容完整无横向滚动
2. 380px 宽下 CTA 按钮不换行、不压字
3. 首屏主图 ≤300 KB（超了必压）
```

## 常见返工点

```
· 把落地页做成海报：只有首屏，没有叙事（用户看完不知道下一步做什么）
· CTA 写「了解更多」——不给动作就是没 CTA
· 桌面好看，手机一开就崩（390 从没测过）
```
