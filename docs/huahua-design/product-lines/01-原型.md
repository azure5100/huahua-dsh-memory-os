# 产品线 01 · 原型

> 能点、能切、能感受流程的高保真界面，重点是「像真的在用一个产品」。


## 何时进这条线

```
用户要：App 界面 / 交互流程 / 可点击 demo / 高保真 mockup
关键词：能点吗、走一遍流程、看看用起来什么样
```

## ① 规格

```
iOS      390×844pt（iPhone 15），设备框必须用 assets/ios_frame.jsx
Android  360×800dp，用 assets/android_frame.jsx
iPad     1024×1366pt
浏览器   1440×900 起，用 assets/browser_window.jsx
交付     默认「平铺 + 可操作」：所有屏幕并排，可点击跳转（不要问，直接给）
```

## ② 必填要素（缺一不算交付）

```
□ 架构选型已声明（静态 HTML / React+Babel，写在文件头注释）
□ 真图已就位（placeshots 之类占位图不算；找不到真图也要说明找了哪些源）
□ 主流程可点通（至少：进入 → 核心操作 → 结果 → 返回）
□ 空状态 / 加载 / 错误 三态至少给一种
□ 设备框用 assets 里的组件，不手写灵动岛与状态栏
```

## ③ 流程四步

```
Step 1  架构选型（静态够用就别上 React；要状态流转才用 React+Babel）
Step 2  找真图：产品图/头像/内容图走 brand-asset-protocol，找不到就明确报告
Step 3  平铺可操作：屏幕并排 + 跳转关系图，边做边能点
Step 4  真实点击测试（Playwright）：点通主流程，截图三个视口
```

## ④ 门禁三条

```
1. Playwright 能点通主流程，控制台零报错
2. 三个视口截图（390 / 768 / 1440）全部布局正常
3. 设备框来自 assets/（手写灵动岛 = 不通过）
```

## 常见返工点

```
· 手写 iOS 状态栏与灵动岛 → 一眼假
· 只有静态截图不能点 → 用户没法「感受流程」
· 用灰色方块当图片占位就交 → 该找的真图没找
```
