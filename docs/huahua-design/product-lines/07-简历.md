# 产品线 07 · 简历

> 一页、可扫读、可选中。它不是作品集，是「6 秒内让人想约你」的文档。


## 何时进这条线

```
用户要：简历 / 求职文档 / 个人介绍单页 / 作品集目录页
关键词：简历、求职、投递、CV、resume
⚠️ 要展示作品图集 → 作品集（走「插画」或「落地页」线），简历只放链接
```

## ① 规格

```
A4 纵向 210×297mm，硬性 1 页（资深可 2 页，但要说明理由）
页边距 上下 15mm / 左右 18mm
正文字号 9-10.5pt（低于 9pt 打印会糊）
行高     1.35-1.5（简历比文档紧，但要能扫读）
交付     PDF（文本可选中，不是图）+ 可编辑源（HTML/MD）
```

## ② 必填要素（缺一不算交付）

```
□ 顶部一句话定位（谁 · 做什么 · 几年 · 要什么岗位）
□ 四分区齐全：定位 / 经历 / 能力 / 联系方式与作品链接
□ 每段经历有「动作 + 结果 + 数字」至少一条
□ PDF 文本可选中可复制（不是导出成图）
□ 一页装得下（超页 = 删内容，不是缩字号）
```

## ③ 流程四步

```
Step 1  先问：投什么岗 / 对方最看重三条什么（决定谁放前面）
Step 2  写内容（先纯文本，不管排版），删到一页装得下
Step 3  排版：四分区 + 统一字号层级（三级足够）
Step 4  打印预览 + 可选中测试 + 改 PDF 元数据（标题写姓名-岗位）
```

## ④ 门禁三条

```
1. 6 秒测试：只看顶部 1/4，能答出「他是谁 / 做过什么 / 凭什么」
2. PDF 文本可选中（用鼠标能选到字，不是位图）
3. 一页装下，打印无断行、无孤页
```

## 常见返工点

```
· 做成视觉作品集：好看但读不出经历（HR 筛的是信息不是审美）
· 导出成图片 PDF → ATS 系统读不到任何字，直接筛掉
· 为了塞内容把字号降到 8pt → 打印模糊，减分
· 没有数字（「负责运营」vs「运营 3 个号，6 个月涨 2 万粉」）
```
