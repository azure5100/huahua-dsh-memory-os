# 产品线 06 · 封面

> 在信息流里 0.3 秒决定点不点 —— 它的唯一 KPI 是缩略图可辨。


## 何时进这条线

```
用户要：公众号封面 / 文章题图 / 视频封面 / 专栏头图
关键词：封面、题图、头图、缩略图
⚠️ 封面里要放大量信息（活动详情）→ 那是「海报」，不是封面
```

## ① 规格

```
公众号封面  2.35:1（900×383 或 1200×510）
公众号方图  1:1（900×900，转载时用）
视频号/抖音 9:16（1080×1920）或 3:4（1080×1440）
安全区      2.35:1 裁切后左右各留 5%，关键元素不出
缩略图测试  缩到 220px 宽仍可辨（这是真门禁）
```

## ② 必填要素（缺一不算交付）

```
□ 视觉主体单一（一个焦点，不要两个主角）
□ 无文字，或文字不占中间（公众号标题会覆盖在图上）
□ 与系列前几期主题色不撞车（系列要有颜色节奏）
□ 缩略图测试截图（220px）
□ 方图（1:1）同时产出（转载要用）
```

## ③ 流程四步

```
Step 1  定「这一期的一个意象」（不要一张图讲三件事）
Step 2  按 2.35:1 构图，把关键元素放中间 90%
Step 3  缩到 220px 看：还认得出是什么吗？认不出就简化
Step 4  出全幅 2.35:1 + 方图 1:1，标注主题色
```

## ④ 门禁三条

```
1. 220px 缩略图下主体可辨
2. 关键元素在 2.35:1 裁切安全区内
3. 方图 1:1 版本存在且不是简单裁切（重新构图）
```

## 常见返工点

```
· 把封面当海报做：细节繁密 → 缩略图糊成一团
· 图中写字 → 被公众号标题压住，双层文字打架
· 系列第 N 期用色和第 N-1 期相同 → 信息流里认不出是新的
```
