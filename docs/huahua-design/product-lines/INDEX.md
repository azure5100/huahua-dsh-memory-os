## 门禁执行纪律

```
① 门禁写不出来 ⇒ 先别加这条产品线（写不出判据 = 交付没有标准）
② 门禁优先可机器验证：缩略图可辨 / 三视口 / 16px / 无孤行 / 二维码真扫
③ 门禁不过就交付 = 记一次返工；同一门禁连续两次不过 ⇒ 改卡（流程或规格错，不是执行错）
```

## 新增产品线怎么写

```
1. 复制 `_TEMPLATE.md`，改四段
2. 在本 INDEX 的「认线速查」加一行（触发词必须和相邻线能区分）
3. 在「门禁一览」加一行（三条门禁，尽量可机器验证）
4. 若依赖外部 skill，只写调用路径，禁止复制其核心资产
```
