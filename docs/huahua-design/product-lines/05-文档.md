# 产品线 05 · 文档

> 长文阅读的排版工程：行宽、行高、分页、导航，四件事决定专业度。


## 何时进这条线

```
用户要：白皮书 / 技术报告 / 提案 / 手册 / 长 PDF
关键词：A4、要打印、发给客户、几十页
```

## ① 规格

```
A4 纵向   210×297mm（595×842pt）
页边距    上 20 / 下 22 / 内 22 / 外 18 mm（留装订）
行宽      ≤66 个中文字符（或 75 个西文字符）
行高      1.5-1.8
正文字号  10.5-11pt；标题 18/14/12pt 三级
图表      与正文间距 8-12pt，图注 9pt
```

## ② 必填要素（缺一不算交付）

```
□ 目录页（章节 + 页码，页码真实对应）
□ 页眉或页脚含文档名/章节名 + 连续页码
□ 行宽 ≤66 字（超了眼睛回行会累）
□ 图注编号连续，正文有引用（「见图 3」）
□ 封面页 + 扉页（标题/副标/日期/版本）
```

## ③ 流程四步

```
Step 1  先定目录（章节骨架），再写字
Step 2  排版规则先落地（行宽/行高/三级标题/页边距）—— 别边写边调
Step 3  插图表：编号 → 图注 → 正文引用，三样齐
Step 4  分页检查 + 导出 PDF（打印预览过一遍）
```

## ④ 门禁三条

```
1. A4 打印预览无孤行（标题不单独落在页底）、无孤字单行成页
2. 页码连续且与目录一致
3. 行宽实测 ≤66 中文字符（截图量一次，不凭感觉）
```

## 常见返工点

```
· 用网页排版思维做印刷（行宽铺满、无分页控制、无页眉页脚）
· 目录页码是手写的，改内容后全错
· 图表无编号无引用 → 读者找不到「刚才那张图」
```
