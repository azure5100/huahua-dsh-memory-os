# 产品线 03 · 海报

> 为「观看距离」和「印刷」设计，不是为屏幕像素设计。


## 何时进这条线

```
用户要：活动海报 / 宣传单页 / 展架 / 易拉宝 / 印刷品
关键词：要打印、贴在墙上、活动宣发、A2/A3/A4
⚠️ 如果只在屏幕上发（朋友圈/群），先确认是否走「封面」或「插画」线
```

## ① 规格

```
A2 展架   420×594mm（+出血 3mm = 426×600）
A3       297×420mm（+3mm）
A4 单页  210×297mm（+3mm）
分辨率    300 dpi，CMYK（屏幕预览用 RGB，交付另出一份）
安全区    四边内缩 5mm，关键文字不出安全区
观看距离  A2 站看 1-2m（主标题 ≥90pt）· A4 手拿 40cm（正文 ≥9pt）
```

## ② 必填要素（缺一不算交付）

```
□ 物理尺寸已声明（mm，不是 px）
□ 3mm 出血已加，5mm 安全区内无关键文字
□ 信息分两级：3 秒读到的（主标题/时间/地点）+ 走近读到的（详情/二维码）
□ 二维码 ≥2cm，四周留白 ≥4 个模块
□ 交付包含：印刷版（CMYK 300dpi）+ 屏幕预览版（RGB）
```

## ③ 流程四步

```
Step 1  先问三件事：贴哪（室内/户外）· 看多远 · 印多大
Step 2  按 mm 建画布 + 出血 + 安全区参考线（不按 px 设计）
Step 3  排两级信息：远看层级 → 近看细节（先做缩小 25% 的测试）
Step 4  出 CMYK 印刷版 + RGB 预览版，检查字体转曲
```

## ④ 门禁三条

```
1. 缩到 25% 仍能读出主标题与时间地点（等于 1.5m 外看 A2）
2. 安全区内零关键文字，出血区无空白边（裁切后不出白边）
3. 交付两个版本（CMYK 300dpi + RGB 预览），字体已转曲或已嵌入
```

## 常见返工点

```
· 按 1920×1080 px 设计却要印刷 → 尺寸与 dpi 全错（这条线最常见的致命错）
· 忘加出血 → 裁切后边缘出白线
· 主标题按屏幕字号（56px）做 A2 → 3 米外完全看不清
· 信息全塞进去不分级 → 远看是一团，近看眼累
```
